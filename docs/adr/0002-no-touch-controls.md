# No touch controls: phones get the Skip View

Status: superseded by [ADR 0005](0005-freelance-home-replaces-the-game.md). The freelance home page replaced the game. The game stays in git history under the tag `game-final`.

The game is desktop only. Phones and other touch-first devices go to the Skip View and do not get on-screen controls. First-person touch controls are hard to make feel good, and many recruiters open links on their phone, so a fast plain page serves them better than a weak game. Touch controls can be added later as a separate input module.
